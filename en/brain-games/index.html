A new Daily Challenge every day

Every day three games are picked as the Daily Challenge. Everyone gets the same three on the same day, so it is easy to compare scores with family and friends. Ten minutes a day is plenty.

The games

  • Sudoku — A workout for the mind, in numbers
  • Nonogram — Shade by the numbers to reveal a picture
  • Queens — One crown per row, column and colour
  • Memory Match — Find the matching picture cards
  • Math Crossword — Sums that add up across and down
  • Number Path — Complete the path of numbers
  • Number Pattern — Fill in the missing number
  • Word Search — Words hidden in the letter grid
  • Maze — Trace the way out with your eyes
  • Spot the Difference — An eye for what has changed
  • Number Pair Match — Find the number that appears twice
  • Mental Math — Add and take away to wake the mind
  • Word Scramble — Put the jumbled letters back in order
  • General Knowledge — What you know, as fast as you can
  • Count the Shapes — Find and count the tangled shapes
  • Number Search — Find the scrambled numbers in order
  • Colour by Number — Fill in the colours, number by number

How it works

  • Each game has five levels. Start where it feels comfortable and move up one step at a time.
  • Your daily scores are saved on your device automatically, so you can see your streak on a chart.
  • Mistakes never cost points. Finishing with time to spare simply earns a bonus.
  • Every puzzle is generated fresh, so you never solve the same one twice.
