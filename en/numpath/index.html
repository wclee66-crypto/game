Number Path — Complete the path of numbers. It has five levels, from a gentle first step to a real challenge. Print the worksheet on A4 paper for free, or download it as a PDF.

Five levels

  • 1. First steps — 4×4 · 5 empty squares
  • 2. Gentle — 5×5 · 9 empty squares · mixed-up path
  • 3. Easy — 5×5 · 13 empty squares · mixed-up path
  • 4. Normal — 6×6 · 21 empty squares · mixed-up path
  • 5. Hard — 7×7 · 33 empty squares · mixed-up path

Scoring

LevelThe board grows and has more blanks — Level 1: 4×4 · Levels 2–3: 5×5 · Level 4: 6×6 · Level 5: 7×7
How to playMake a path from 1 to the last number, with each number touching the next up, down, left, or right. Tap the blank square for the number shown above
Path pointsUp to 600 · in proportion to the blanks filled correctly
Time bonusUp to 300 · only if you finish, in proportion to time left
Focus bonusUp to 100 · for every grid finished without a single slip
Wrong-answer penaltyNone — a wrong tap only flashes the cell red for a moment
Level bonusNormal +100, Hard +250 (when you finish)
Top scoreLevels 1–3: 1,000 · Normal: 1,100 · Hard: 1,250
