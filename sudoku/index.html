새록은 치매를 예방하고 인지 능력을 지키는 데 도움이 되도록 만든 두뇌 훈련 놀이터입니다. 컴퓨터·휴대폰·태블릿 어디서나 열리고, 화면이 불편하시면 문제를 종이에 뽑아 연필로 푸셔도 됩니다.

난이도 5단계

  • 1단계 첫걸음 — 4칸 판 · 숫자 1~4
  • 2단계 가볍게 — 6칸 판 · 숫자 1~6
  • 3단계 쉬움 — 9칸 판 · 숫자 45개로 시작
  • 4단계 보통 — 9칸 판 · 숫자 34개로 시작
  • 5단계 어려움 — 9칸 판 · 숫자 28개로 시작
