# 맑은뜰 — 치매 예방 두뇌 훈련 플랫폼

스도쿠 · 낱말찾기 · 상식 퀴즈 세 가지 게임을 한 화면 안에서 오가며 즐기고,
**하루 단위로 점수가 저장·관리되는** 모바일/태블릿용 웹 앱입니다.
설치 프로그램이나 서버 없이 브라우저만 있으면 동작하며, 한 번 설치하면 인터넷 없이도 실행됩니다.

**실행 주소:** https://malgeunddeul.netlify.app

---

## 1. 실행과 설치

### 휴대폰·태블릿·PC에서 쓰기

1. 브라우저로 위 주소를 엽니다.
2. 화면 맨 위에 나오는 안내대로 앱을 설치합니다.
3. 홈 화면(또는 바탕화면)의 「맑」 아이콘으로 실행합니다. 주소창이 보이지 않으면 정상 설치된 것입니다.

설치가 끝나면 **인터넷이 없어도, PC가 꺼져 있어도** 실행됩니다. 파일이 기기 안에 저장되기 때문입니다.

### 설치 안내는 앱이 알아서 띄웁니다

홈 화면 맨 위에 지금 상황에 맞는 안내가 나옵니다.

| 상황 | 표시 |
|---|---|
| 크롬 계열이 설치를 허용 | **「앱으로 설치하기」 버튼** — 누르면 바로 설치 |
| 안드로이드인데 버튼이 안 뜸 | 브라우저 메뉴 `⋮` → **앱 설치** 안내 (새로고침 후 재시도) |
| 아이폰·아이패드 Safari | 공유 버튼 `⬆` → **홈 화면에 추가** 안내 |
| 아이폰인데 Safari가 아님 | Safari로 열어 달라는 안내 |
| 카카오톡·네이버 앱 안 | 설치 불가 — **다른 브라우저로 열기** 안내 |
| 이미 앱으로 실행 중 | 아무것도 표시하지 않음 |

- 크롬은 **서비스 워커가 페이지를 넘겨받은 뒤에야** 「앱 설치」를 제공합니다.
  첫 방문에서는 「홈 화면에 추가」(주소창이 있는 단순 바로가기)만 보이므로 **새로고침을 한 번** 하세요.
- 아이폰은 「앱 설치」 메뉴 자체가 없습니다. Safari의 **홈 화면에 추가**가 정식 설치 방법입니다.

### 개발용 로컬 실행

```bash
node server.js
```

`http://localhost:8123` 에서 열립니다. `index.html` 을 브라우저로 직접 열어도 게임은 동작합니다
(이때는 오프라인 캐시와 홈 화면 설치가 적용되지 않습니다).

> `http://192.168...` 같은 주소로는 브라우저가 서비스 워커를 막기 때문에 앱 설치·오프라인 실행이 되지 않습니다.
> 반드시 `https` 주소에서 설치해야 합니다.

## 2. 화면 구성과 게임 전환

아래쪽 **탭 막대**가 항상 떠 있어 어느 게임에서든 한 번의 터치로 다른 게임으로 넘어갑니다.

```
[ 홈 ] [ 스도쿠 ] [ 낱말찾기 ] [ 상식퀴즈 ] [ 기록 ]
```

- 게임 화면 안에도 **⇄ 다른 게임** 버튼이 있어, 판을 끝낸 직후에도 바로 이동할 수 있습니다.
- **진행 중인 판은 자동 저장**됩니다. 스도쿠를 풀다가 퀴즈로 갔다가 돌아오면
  숫자·메모·시간이 그대로 남아 있고, 시작 화면에 **이어서 하기** 버튼이 나타납니다.
  (진행 중인 판은 그날 자정까지만 유지됩니다.)
- 각 게임은 화면에서 내려가는 순간 타이머와 예약된 그리기를 모두 멈춥니다.
  그래서 게임을 바꾼 뒤에 이전 게임 화면이 덮어써지는 일이 없습니다.

## 3. 점수 규칙

**세 게임 모두 기본 1,000점 만점**입니다. 어려운 난이도를 고르면 보너스가 더해져
한 게임 최고 1,250점, **하루 만점은 3,750점**입니다.

### 3-1. 스도쿠

| 항목 | 내용 |
|---|---|
| 완성 기본 | 문제를 다 풀면 **500점** |
| 시간 보너스 | 최대 **300점** — `300 × (남은 시간 ÷ 제한 시간)`<br>제한 시간: 4분 / 7분 / 8분 / 12분 / 18분 (1~5단계) |
| 정확도 보너스 | 최대 **200점** — `200 − (실수 × 40)`, 최저 0 |
| 힌트 감점 | 힌트 1회마다 **−50점** |
| 난이도 보너스 | 보통 **+100점**, 어려움 **+250점** (1~3단계는 없음) |
| 최고 점수 | 1~3단계 1,000 / 보통 1,100 / 어려움 1,250 |

**난이도 5단계** — 앞 두 단계는 판 자체가 작습니다. 숫자만 많이 줘서는 9칸 판이 쉬워지지 않기 때문입니다.

| 단계 | 이름 | 판 | 시작 숫자 | 제한 시간 | 보너스 |
|---|---|---|---|---|---|
| 1 | 첫걸음 | **4×4** (숫자 1~4) | 8개 | 4분 | — |
| 2 | 가볍게 | **6×6** (숫자 1~6) | 20개 | 7분 | — |
| 3 | 쉬움 | 9×9 | 45개 | 8분 | — |
| 4 | 보통 | 9×9 | 34개 | 12분 | +100 |
| 5 | 어려움 | 9×9 | 28개 | 18분 | +250 |

- 모든 단계에서 **해가 하나뿐인** 문제만 출제합니다.
- 다 풀지 않고 나가면 **점수는 기록되지 않습니다.** (진행 상황만 저장)

### 3-2. 낱말찾기

| 항목 | 내용 |
|---|---|
| 낱말 점수 | 최대 **600점** — `600 × (찾은 낱말 ÷ 전체 낱말)` |
| 시간 보너스 | 최대 **300점** — 모든 낱말을 찾았을 때만, `300 × (남은 시간 ÷ 제한 시간)` |
| 정확도 보너스 | 최대 **100점** — `100 − (헛선택 × 10)`, 최저 0 |
| 힌트 감점 | 힌트 1회마다 **−50점** |
| 난이도 보너스 | 보통 **+100점**, 어려움 **+250점** (모두 찾았을 때만 · 1~3단계는 없음) |
| 최고 점수 | 1~3단계 1,000 / 보통 1,100 / 어려움 1,250 |

**난이도 5단계**

| 단계 | 이름 | 판 | 낱말 | 방향 | 제한 | 보너스 |
|---|---|---|---|---|---|---|
| 1 | 첫걸음 | 6×6 | 4개 (세 글자 이하) | 가로·세로만 | 5분 | — |
| 2 | 가볍게 | 7×7 | 5개 (세 글자 이하) | + 대각선 | 5분 | — |
| 3 | 쉬움 | 8×8 | 6개 | →, ↓, ↘ | 6분 | — |
| 4 | 보통 | 10×10 | 8개 | + 거꾸로 | 8분 | +100 |
| 5 | 어려움 | 12×12 | 10개 | 여덟 방향 | 10분 | +250 |

- 1·2단계는 **짧은 낱말이 넉넉한 주제**만 골라 출제합니다.
- 주제(과일·채소·동물·꽃·먹거리·몸·살림살이·자연·명절·놀이·나라·직업 12가지)는 판마다 무작위입니다.
- 고르는 방법이 두 가지입니다.
  - **그어서 고르기**: 첫 글자에서 마지막 글자까지 손가락으로 끕니다. 손을 떼면 확정되고,
    낱말이 아니면 헛선택 1회로 셉니다.
  - **눌러서 고르기**: 글자를 하나씩 차례로 누릅니다. **낱말이 완성될 때까지 선택 색이 그대로 남고**,
    중간 단계는 헛선택으로 세지 않습니다. 시작 칸을 다시 누르면 취소, 곧지 않은 방향의 칸을 누르면
    그 칸부터 새로 시작합니다. (손을 떨거나 화면을 끌기 어려운 분을 위한 방식)
- 시간이 끝나면 **그때까지 찾은 만큼만** 점수로 기록됩니다.

### 3-3. 상식 퀴즈

| 항목 | 내용 |
|---|---|
| 정답 점수 | 최대 **700점** — `700 × (맞힌 문항 ÷ 전체 문항)` |
| 속도 보너스 | 최대 **200점** — 정답 문항의 남은 시간 비율 합계 기준 |
| 연속 정답 보너스 | 최대 **100점** — 3연속 25 / 4연속 50 / 5연속 75 / 6연속 이상 100 |
| 오답 감점 | **없음** (틀려도 점수가 깎이지 않습니다) |
| 난이도 보너스 | 보통 **+100점**, 도전 **+250점** (끝까지 풀었을 때 · 1~3단계는 없음) |
| 최고 점수 | 1~3단계 1,000 / 보통 1,100 / 도전 1,250 |

- 분야: 전체 · 역사 · 속담/표현 · 자연/과학 · 생활/건강 · 문화/전통 · 두루상식
- 문제 은행 **138문항**, 문제와 보기 순서는 매번 무작위로 섞입니다.

**난이도별 차이** — 문항 수·시간·문제의 어려움이 함께 달라집니다.

| 단계 | 이름 | 문항 | 보기 | 문항당 시간 | 출제 범위 | 보너스 |
|---|---|---|---|---|---|---|
| 1 | 첫걸음 | 5 | **2개** | 40초 | 쉬운 문제만 (d1) | — |
| 2 | 가볍게 | 8 | **3개** | 30초 | 쉬운 문제만 (d1) | — |
| 3 | 기본 | 10 | 4개 | 25초 | 쉬운 문제 위주 (d1·d2) | — |
| 4 | 보통 | 15 | 4개 | 16초 | 보통 이상 (d2·d3) | +100 |
| 5 | 도전 | 20 | 4개 | 10초 | **어려운 문제만 (d3)** | +250 |

- 보기를 줄일 때는 **정답 하나에 오답을 필요한 만큼만** 남깁니다. 넷에서 둘로 줄면 체감 난이도가 크게 떨어집니다.

- 문제마다 `d` 값(1 쉬움 / 2 보통 / 3 어려움)이 붙어 있고, 난이도별로 그 범위에서만 출제합니다.
  현재 쉬움 59 · 보통 31 · **어려움 48문항**.
- 특정 분야를 골랐는데 그 난이도의 문제가 모자라면, 남은 문제 중 **어려운 것부터** 채워 문항 수를 맞춥니다.

**오답 노트 (틀린 문제만 다시 풀기)**

- 틀린 문제와 시간이 지나 넘어간 문제는 **자동으로 오답 노트에 쌓입니다** (최대 200문제).
- 다시 푸는 방법은 두 가지입니다.
  - 퀴즈가 끝난 결과 화면의 **「틀린 문제만」** 버튼 → 방금 틀린 문제를 바로 이어서 복습
  - 퀴즈 시작 화면의 **「틀린 문제만 다시 풀기」** 버튼 → 그동안 쌓인 오답을 한 번에 최대 20문제씩
- 복습에서 **다시 맞히면 그 문제는 노트에서 지워집니다.** 틀리면 그대로 남습니다.
- 복습은 **연습이므로 점수로 기록되지 않습니다.** (문항 수가 적어 점수가 왜곡되는 것을 막기 위함)
  결과 화면에는 맞힌 문제 수와 노트에 남은 문제 수를 보여 줍니다.
- 일반 퀴즈에서 맞힌 문제도 노트에 있으면 함께 지워집니다.
- 노트를 통째로 비우려면 시작 화면 아래의 **「오답 노트 비우기」** 를 누르세요.

## 4. 점수 기록 방식

- 한 판이 끝날 때마다 **날짜 · 게임 · 난이도 · 점수 · 걸린 시간 · 세부 내역**이 기기에 저장됩니다.
- **그날의 총점 = 게임별 “그날 최고 점수”의 합**입니다.
  같은 게임을 여러 번 해도 총점에는 가장 잘한 판만 반영되고, 판별 기록은 모두 남습니다.
- 홈 화면: 오늘 총점, 종목별 오늘 최고점, **연속 플레이 일수**, 최근 7일 막대그래프
- 기록 화면: 총 판수 / 플레이한 날 / 연속 일수 / 판당 평균, 최근 2주 그래프,
  게임별 역대 최고 기록, **날짜별 상세 내역**(펼치면 판별 기록), 내보내기·가져오기·초기화
- 저장 위치는 이 기기의 브라우저 저장소(localStorage), 키는 `malgeunddeul.v1`. 최근 400일치 보관.
- **기록 내보내기**로 `맑은뜰-기록-YYYY-MM-DD.json` 파일을 만들고, **기록 가져오기**로 다시 불러옵니다.
  같은 판이 두 번 들어가지 않도록 걸러 내므로, 두 기기의 기록을 합치거나
  **다른 주소로 앱을 옮길 때 점수를 그대로 가져올 수 있습니다.**
  (점수는 주소별로 따로 저장되므로, 주소를 바꾸면 반드시 이 과정을 거쳐야 합니다.)

## 5. 어르신을 위한 배려

- 글씨 크기 3단계(보통 / 크게 / 아주 크게) — 오른쪽 위 **⚙ 설정**에서 변경
- 모든 버튼은 충분히 크고, 흰 바탕에 높은 명암비
- 소리 신호(정답·오답·완성) 켜기/끄기
- 낱말찾기는 **긋기**와 **한 글자씩 누르기** 둘 다 지원
- 스도쿠는 틀린 숫자를 즉시 빨갛게 표시하고, 메모(연필) 기능 제공
- 퀴즈는 오답 감점이 없어 부담 없이 도전 가능
- 종이로 푸는 분을 위한 **A4 문제지 인쇄** (아래 6번)
- **난이도 5단계** — 4×4 스도쿠, 6칸 낱말판, 2지선다 퀴즈부터 시작할 수 있습니다

## 6. 종이로 풀기 — A4 문제지 인쇄 / PDF 저장

연필로 푸는 분(특히 화면 조작이 어려운 어르신)을 위해 **스도쿠**와 **낱말찾기**는
종이 문제지로 뽑을 수 있습니다. 각 게임의 시작 화면에서 **「종이로 풀 문제 만들기」** 를 누르세요.

- **고를 수 있는 것**: 난이도 · 장수(1·2·4장) · 정답지 포함 여부
- 누를 때마다 **새 문제**가 만들어집니다 (화면에서 진행 중인 판과는 무관)
- 인쇄 창에서 **대상**을 **“PDF로 저장”** 으로 고르면 PDF 파일이 됩니다

**문제지에는 게임 화면의 정보가 들어가지 않습니다.** 시간·힌트·실수·점수·버튼·메뉴는 모두 빠지고,
아래 것만 A4 한 장에 크게 담깁니다.

| | 스도쿠 | 낱말찾기 |
|---|---|---|
| 머리글 | 제목 · 난이도 · **이름/날짜 적는 칸** | 제목 · 주제 · 이름/날짜 칸 |
| 본문 | 고른 단계의 판 (4×4·6×6·9×9 — 판이 작으면 칸이 커집니다) | 글자판 (판 크기에 맞춰 자동 확대) |
| 안내 한 줄 | 푸는 방법 | 푸는 방법 |
| 아래 | — | **찾을 낱말 목록** |
| 정답지(선택) | 채워 넣은 칸은 흐리게 구분 | 낱말 위치를 굵은 테두리로 표시 |

> 인쇄는 **PC와 안드로이드**에서 가장 잘 됩니다. 아이폰은 Safari에서 공유 → 프린트로 저장하세요.

## 7. 앱 아이콘

## 8. 배포와 업데이트

1. `pack.cmd` 를 두 번 누릅니다.
   - `js/app.js` 의 `APP_VERSION` 과 `sw.js` 의 `VERSION` 을 **자동으로 하나 올리고**
   - 실행에 필요한 파일만 골라 상위 폴더에 `맑은뜰-배포용.zip` 을 만듭니다.
2. 그 zip 을 Netlify 프로젝트의 **Production deploys** 영역에 끌어다 놓습니다.
3. 끝입니다. 설치된 모든 기기가 다음 실행 때 자동으로 최신이 됩니다.

**버전 확인:** 앱의 **⚙ 설정** 화면에 현재 버전이 표시됩니다.
그 아래 **「최신 버전으로 새로 받기」** 버튼은 서버 연결을 먼저 확인한 뒤에만 갱신하며,
연결되지 않으면 **아무것도 지우지 않습니다**(저장본과 점수를 보호). 점수 기록은 어떤 경우에도 지워지지 않습니다.

### 캐시 정책

`sw.js` 는 **네트워크 우선**입니다.

- 인터넷이 되면 항상 새 파일을 먼저 받아 옵니다 → 고친 내용이 **한 번의 실행으로** 반영됩니다.
- 연결이 안 되면 저장본으로 실행합니다.
- 서버가 죽어 **오류 응답(502·530 등)** 이 오는 경우에도 저장본으로 넘어갑니다.
  이 처리가 없으면 오류 페이지가 그대로 화면에 뿌려져 설치된 앱이 깨집니다.
- 저장본조차 없으면 「다시 시도」 버튼이 있는 안내 화면을 보여 줍니다.

### 게임을 새로 추가하려면

`js/games/` 에 아래 모양의 객체를 만들어 `window.Games.<id>` 로 등록하고,
`index.html` 에 스크립트 한 줄, `js/app.js` 의 `GAMES` 배열에 id 하나를 더하면 됩니다.

```js
window.Games.myGame = {
  id: 'myGame', name: '새 게임', icon: '★',
  rules: { title: '…', lines: [['항목', '설명'], …] },
  mount: function (container) { /* 화면 그리기 */ },
  unmount: function () { /* 타이머 정리 + 진행 상황 저장 */ },
  hasProgress: function () { return !!Store.getSession('myGame'); }
};
```

점수 기록은 `Store.addRecord({ game, score, difficulty, duration, detail })` 한 줄이면 됩니다.

> **주의:** `mount` 에서 건 타이머·예약(`setTimeout`)은 반드시 `unmount` 에서 정리해야 합니다.
> 정리하지 않으면 다른 게임으로 넘어간 뒤에 예약이 터져 새 게임 화면을 덮어씁니다.

## 10. 만들어진 방식

- 순수 HTML/CSS/JavaScript. 빌드 도구도, 외부 라이브러리도 쓰지 않습니다.
- 스크립트는 모두 고전적인 `<script>` 방식이라 `file://` 로 열어도 동작합니다.
- 글꼴은 Google Fonts(고운바탕 · Gothic A1)를 쓰고, 없으면 기기 기본 한글 글꼴로 넘어갑니다.
